# Site Factory — Status Snapshot (2026-02-09)

## Goal (V1)
Build a "site factory" for many service sites (Landing/Service/Blog) with:
- Astro SSG output
- Self-hosted admin panel on WHM/cPanel (no external dependency)
- Per-site admin (multi-tenant + roles)
- Widget-based Page Builder (Home + Service sections with reorder)
- Blog: fixed template + rich text + featured image + categories/tags
- SEO + Schema Builder (FAQ, LocalBusiness, Service, Article, Breadcrumb, ...)
- Media: local upload + Aparat embed
- Deploy: atomic deploy + rollback + no downtime

## Infra constraints
- Iran: international internet may be cut → must work offline from external services
- Server: AlmaLinux 8.10, cPanel & WHM v132.0.22, full SSH
- Panel domain: https://5dm.ir/ (dedicated)
- Priority: lowest-risk approach; isolate everything from other hosted sites

## Final architecture decisions
- Central panel: Payload CMS (self-hosted)
- Multi-site: multi-tenant with roles & access control
- Site output: Astro (later)
- Media: stored on server + Aparat embed
- Build/deploy: internal runner + atomic symlink switch (later)
